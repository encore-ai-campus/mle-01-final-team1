## 4. 품질 판단

- 상품 ID와 정책 ID 중복은 확인되지 않았다.
- 금리옵션 복합키는 상품·가입기간·금리유형·적립유형·상환방식을 포함해 검사했으며, 동일 조건 중복 여부는 위 표의 결과를 따른다.
- 가입기간·금리·연령·소득은 표준 숫자 필드로 분석 가능하다.
- 지역·직업·학교 코드는 배열화됐지만 코드명 매핑은 아직 없다.
- 신청기간은 아직 원문 문자열이므로 시작일·종료일 비교가 불가능하다.
- 평균금리와 공시 최저·최고금리는 기준이 다를 수 있으므로 하나의 범위로 보정하면 안 된다.
